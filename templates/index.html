1. GitHub (Version Control & Webhook)

Developers push code changes to GitHub. An automated webhook immediately notifies Jenkins of incoming commits.

2. Jenkins (CI/CD Automation Engine)

Jenkins automatically checks out code, runs automated tests, builds the container image, and handles authentication.

3. Docker (Containerization)

Docker packages the application into a lightweight, isolated image tagged with the traceable build number or commit SHA.

4. Amazon ECR (Private Container Registry)

The tagged Docker image is authenticated and securely pushed to private Amazon Elastic Container Registry (ECR).

5. Docker Swarm on EC2 (Container Orchestration)

Docker Swarm pulls the new image from ECR and executes a zero-downtime rolling update across the manager and worker EC2 nodes.
