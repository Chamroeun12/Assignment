1. Source Control (Git)

Developers commit code to branch-protected GitHub repository, triggering automated CI/CD webhooks.

2. Build & Test

Pytest unit/integration test suite and Flake8 linter run automatically on Python 3.10 with coverage validation.

3. Quality & Security Scan

SonarQube scans code quality and Trivy executes CVE vulnerability scanning on Docker images and K8s manifests.

4. Amazon ECR Registry

Docker container image is tagged with immutable git SHA and pushed to private Amazon ECR repository.

5. GitOps Manifest Automation

CI pipeline updates K8s deployment image reference in repository with [skip ci] to avoid loops.

6. Argo CD Sync

Argo CD reconciles live Amazon EKS cluster state with the GitOps desired state repository.

7. Kubernetes Pod Health

Pods provision with unprivileged non-root UID 1000, resource limits, and HTTP /health probes.

8. Zero-Downtime Rollout

Zero-downtime Rolling Update (maxSurge=1, maxUnavailable=0) and documented Blue-Green candidate switching.

9. Full-Stack Observability

Prometheus scrapes metrics, Grafana visualizes pod health, and CloudWatch forwards container logs.

10. Safe Rollback

Git-authoritative revert triggers instant Argo CD rollback without configuration drift conflicts.
